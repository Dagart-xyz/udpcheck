# Как помочь

Правки приветствуются: баги, названия провайдеров, тесты, переводы, новые способы проверки.

1. Прочитайте [PRIVACY-PRINCIPLES.md](PRIVACY-PRINCIPLES.md): правки, ухудшающие приватность посетителей, не принимаются.
2. Запустите тесты (`python tests/test_v2_local.py` и остальные `tests/test_*.py`, `tests/names_selftest.py`). Код пишем на стандартной
   библиотеке Python 3.10+, без внешних зависимостей.
3. В описании правки напишите, что и зачем меняется. Подписывая коммит (`git commit -s`), вы подтверждаете, что имеете право передать код
   на условиях AGPL-3.0-or-later (Developer Certificate of Origin, https://developercertificate.org).
4. Об уязвимостях сообщайте по [SECURITY.md](SECURITY.md), не в публичных задачах.

Названия провайдеров правятся в `brands.json` (операторы из нескольких сетей) и `names.json` (имя по номеру AS) на сервере; предложения присылайте
задачей с номером сети и желаемым названием.
